# Nimbo competition source

- `src/game.js`: gameplay, WebGL renderer, models and synthesized audio.
- `src/page.html`: English game interface and controls.
- `src/page.css`: responsive interface styling.

Run `npm run build` at the repository root to generate `public/nimbo.zip` and the identical `public/entry/index.html`. The hard limit is 13,312 bytes.

See [release guide](../workfiles/release/README.md) for rules, checks, provenance and reproduction instructions.
