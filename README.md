# Nimbo

A little cloud magic. Build a staircase of rainbow clouds for an automatically climbing unicorn, complete glowing checkpoints, and stay ahead of the fog.

![Nimbo](public/press/cover.png)

**[Download the 13KB game](public/nimbo.zip)** · [Readable source](js13k/src/game.js) · [Build, controls and credits](workfiles/release/README.md) · [Submission draft](workfiles/release/submission.md)

```sh
npm ci --ignore-scripts
npm run build
npm run dev
```

Play at http://localhost:8080. Node 24+; release reproduction uses Node 26.8.1.

The game is entirely procedural: models, rainbow shaders, sparkles and synthesized music. No accounts, servers or network assets are needed to play the ZIP.
